实际用 uv 0.10 建环境并装完全部依赖验证：

```

uv pip install --index-url 清华源 -r requirements.txt → 5.4 秒装完 32 个包
DATABASE_URL=... /tmp/venv/bin/python -c "from app.main import app"  → 无导入错误
health / create content / queue / tools / render  → 全部 200
```

选清华源前用默认 PyPI 源明显更慢，配好 `~/.config/uv/uv.toml` 后装依赖基本秒级。

## 四、开发过程中修复的真实 Bug

这些都已在代码里修掉，记录在此避免回归：

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 前端表格只渲染表头，正文空白 | `NTable` 配 render 列定义会静默丢行 | 换 `NDataTable` |
| 2 | 系统状态页 AI 状态加载后崩溃 | `const [h, t] = await ...` 遮蔽了从 vue 导入的渲染函数 `h` | 局部变量改名 |
| 3 | 前端探活永远 404 | 前端 axios baseURL 是 `/api`，而 health 只挂在 `/health` | 增加 `/api/health` |
| 4 | iPad（820px）掉进手机布局 | 断点设成 820px，把 iPad 也算作移动端 | 断点改 768px |
| 5 | 移动端底导显示成源码文本 | 菜单项 label 用函数式写法（兼容 NeMenu），直接渲染出函数体 | 底导改用独立静态配置 |
| 6 | 移动端表格列被挤压 | 无横向滚动 | 加 `scroll-x` |
| 7 | 服务启动报 `no such table: contents` | `create_all` 只认已 import 的模型 | `models/__init__.py` 聚合导出 |
| 8 | pnpm 12 下 `--frozen-lockfile` 被拒 | pnpm 12 默认 `minimumReleaseAge=24h`，锁文件里有当天发布的包 | `package.json` 锁 pnpm 10.28.2 + `.npmrc` 设 `minimumReleaseAge=0` |
| 9 | 移动端内容最后一行被底导遮挡 | fixed 定位未预留空间 | `padding-bottom: calc(76px + safe-area-inset-bottom)` |

> 说明：其中 8 号是真实踩到的坑——同样的 `pnpm install` 在 pnpm 10 下正常，换 pnpm 12 直接报「锁文件包含被策略拒绝的条目」。所以版本要锁死。
