# 小云雀（Pippit）生视频接入指引

> 版本：1.9.0 起支持 · 2026-10-28

## 一、先弄清一件事：小云雀的开放接口在哪

小云雀有两个完全不同的入口，**只有一个能编程调用**：

| 入口 | 地址 | 能否调用 |
|---|---|---|
| 网页端 / App / 桌面端 | `xyq.jianying.com` | ❌ 给人和 Agent 用的，无开放 API |
| 开放 API | `visual.volcengineapi.com`（火山引擎「视觉智能」下） | ✅ 本模块接的就是这个 |

开放 API 的服务标识（`req_key`）是 `pippit_iv2v_cvtob`，对应「小云雀-智能生视频 Agent 1.0」。

**开放的能力只有两条线，都是视频：**

| 能力 | 说明 |
|---|---|
| 智能生视频 Agent | 一句话提示词 + 可选参考图/参考视频 → 15-60 秒成片 |
| 营销成片 Agent | 商品名称 + 商品主图 + 可选模特图 → 带货营销片 |

网页端/App 里的「AI 海报、换背景、字幕擦除、数字人口播」**没有开放接口**。如果你要的是**文章配图**，这个模块帮不上——那需要接生图模型（Seedream / 即梦，同样在火山视觉下，同一套签名，加一个 `req_key` 就行）。

## 二、开通步骤

1. **注册火山引擎账号**：<https://www.volcengine.com/>（个人/企业均可）
2. **创建 Access Key**：控制台 → 右上角头像 → 「访问控制」→「密钥管理」→ 新建密钥
   - 记录 **Access Key ID**（形如 `AKLT...`）与 **Secret Access Key**（一串 Base64）
   - Secret Key **只显示一次**，关掉就没法再看了，务必当场保存
3. **开通小云雀服务**：控制台搜索「智能视觉」→ 服务列表里找「小云雀-智能生视频 Agent」→ 点「立即开通」
   - 不同账号的免费试用额度不同，以你自己的控制台显示为准
4. **确认权限**：确保这个 AK 所属账号/子用户有 `cv` 服务的调用权限。子账号需要单独授权，主账号一般默认有。

## 三、配置

编辑 `backend/.env`：

```ini
VOLC_ACCESS_KEY=你的AccessKeyID
VOLC_SECRET_KEY=你的SecretAccessKey
VOLC_REGION=cn-north-1
VOLC_TIMEOUT=30

PIPPIT_POLL_INTERVAL=5
PIPPIT_TIMEOUT=600
PIPPIT_MAX_MB=200
```

改完重启后端：

```bash
./.PlnPyKFp4CRfFtgC1/bin/supervisord -c ./.PlnPyKFp4CRfFtgC1/supervisord-conf/supervisord.conf ctl restart cwb-backend
```

## 四、验证凭证是否可用

配好后运行这条命令，它会用你的**真实凭证**提交一个最小的测试任务：

```bash
cd backend && python3.11 - <<'PY'
import asyncio
from app.services import pippit

async def main():
    # 只验证「凭证 + 权限 + 签名」是否都对，不打满整个生成流程
    task_id = await pippit.submit_video(prompt="一只橘猫在洒满阳光的窗台上打哈欠，慢镜头")
    print("提交成功，task_id =", task_id)
    print("接下来可用 pippit.query_video(task_id) 查状态，或用 pippit.wait_video(task_id) 等到出片")

asyncio.run(main())
PY
```

**三种典型结果怎么读：**

| 现象 | 含义 | 怎么办 |
|---|---|---|
| 打印出 `task_id` | 全部配置正确 | 可以用了 |
| `InvalidAccessKey`（100009） | AK 不存在或写错了 | 核对第 2 步拿到的 AK |
| `InvalidSignature` | Secret Key 不对 | 重新下载密钥，注意别漏字符 |
| `服务未开通` / 权限类错误 | 服务没开或子账号无权限 | 回到第 3、4 步 |
| 提示词审核未通过（50412/50413） | 内容含敏感词 | 换个说法，别测政策敏感内容 |

## 五、代码里的三个硬约束

这些不是「建议」，是接好之后还会反复咬你的点：

### 1. 返回的视频链接只有 1 小时

`CVSync2AsyncGetResult` 返回的 `video_url` **1 小时后失效**。所以拿到就必须立刻下载转存：

```python
info = await pippit.query_video(task_id)
if info["done"]:
    data = await pippit.download_video(info["video_url"], max_mb=200)
    # 立刻落盘 / 入素材库，别只存 URL
```

只存 URL 的后果是：第二天打开历史任务，全是死链。

### 2. AI 生成标识必须开

请求体里的 `enable_watermark` 本模块**硬编码为 `True`，没有开关**。开启后左上角显示「AI生成」、右下角显示「小云雀AI生成」。

依据是《人工智能生成合成内容标识办法》——AI 生成内容必须显著标识。别想着关掉，那是违规。

另有隐式标识参数 `req_json.aigc_meta`（`producer_id` / `content_propagator`），需要填你自己的主体 ID，目前未接入，等你有主体编号再加。

### 3. 任务 12 小时过期

`status` 出现 `not_found` 或 `expired` 就是过期了，只能重新提交（会再扣一次额度）。

`wait_video()` 超时**不等于失败**：任务还在服务端跑，拿 `task_id` 继续查即可，不用重新提交。代码里的超时提示专门写了这句，就是防止用户误操作白扣额度。

## 六、参数速查

| 参数 | 可选值 | 备注 |
|---|---|---|
| `ratio` | `16:9` / `9:16` / `4:3` / `3:4` | 不传 = Agent 自己推荐 |
| `duration` | `～15s` / `～30s` / `40～60s` | ⚠️ **全角波浪号**，半角 `~` 会被拒 |
| `language` | `Chinese`（默认）/ `English` / 日语 / 泰语… | 共 16 种 |
| `accent` | `PuTongHua`（默认）/ 东北话 / 河南话 / 粤语 / 四川话… | 口音 |
| `img_url_list` | 公网可访问的图片 URL | 图 + 视频合计 ≤ 50，单图 ≤ 20MB |
| `video_url_list` | 公网可访问的视频 URL | 单个 ≤ 3 分钟、≤ 200MB |
| `prompt` | 文本 | ≤ 2000 字，超了会「概率异常或指令不生效」 |

「全角波浪号」这个坑很隐蔽：文档原文就是 `"～15s"`，看起来像排版瑕疵，但用半角就被拒。代码里已在本地校验挡掉，并写了测试防止有人「顺手改成 ASCII」。

## 八、关于签名：一个必须记下来的坑

自己写火山 V4 签名时，官方文档有一句话极具误导性：

> 「后三步将上一步结果作为 **Hex 类型** 密钥传入」

照字面理解（把上一步的十六进制字符串当 key）算出来的签名**一定错**。实测正确做法是：**每一步都直接拿上一步 HMAC 输出的 raw bytes 当 key**。

`tests/test_volcengine_sign.py` 里用官方文档公布的示例凭证和期望签名做了回归，逐层核对 `kRegion` / `kService` / `kSigning` 三级全部吻合。以后任何人改动这段签名代码，跑测试就知道有没有改坏。

另外，签名只覆盖 `host` 与 `x-date` 两个头（官方 Java SDK 示例签了四个，两种都能通过）。选最小集是刻意的：一旦某个网关给 `Content-Type` 补上 `; charset=utf-8`，签了它的版本会立刻失效，而报错只会说 `InvalidSignature`，极难排查。
