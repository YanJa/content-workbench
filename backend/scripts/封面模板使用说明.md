# 码上聊聊 · 公众号封面模板使用说明

> **已接入内容运营工作台**（2026-10-16）。相对原始版本的改动：
> ① 去掉写死的 Windows 路径，`BASE` 取脚本自身目录，浏览器自动探测
> （`COVER_CHROME` 环境变量 → 常见路径 → `PATH`）；
> ② `--out` 可传目录（后端统一传输出目录，按「cover-风格-尺寸-日期.png」命名）；
> ③ 渲染加 `--no-sandbox`（容器内 root 必需），失败给可读中文报错。
>
> 工作台里的调用方是 `backend/app/services/covers.py`，配置项 `COVER_SCRIPT`
> /`COVER_TAG`/`COVER_STYLE`/`COVER_SIZE`。前端「配图 → 封面（头图）」区块
> 可直接填标题/副标题/标签 + 选风格生成，排版时也会自动出封面。

一套**参数化封面生成器**：改文字出新图，不用每次重新设计。
品牌主色、装饰气泡、品牌角标全部自动带上，风格永远统一。

## 二、全部参数

| 参数 | 说明 | 示例 |
|---|---|---|
| `--title` | **必填**。主标题，`\n` 手动换行 | `"AI 帮你写周报\n10 分钟搞定 3 小时"` |
| `--sub` | 副标题（可省） | `"实测一个月，只留这 3 个"` |
| `--tag` | 左上角标签（可省） | `"第 12 期"` / `"教程"` / `"新鲜事"` |
| `--date` | 日期，显示在标签旁（可省） | `"2026.10.13"` |
| `--style` | `gradient` 渐变 / `dark` 深色 / `light` 浅色 | 默认 gradient |
| `--size` | `wide` 900×383 / `square` 800×800 / `og` 1200×630 | 默认 wide |
| `--scale` | 渲染倍数，默认 2（= 1800×766 高清） | 一般不动 |
| `--out` | 自定义输出文件名 | 可省 |

---

## 三、三种风格怎么选

| 风格 | 底色 | 适合内容 | 视觉感受 |
|---|---|---|---|
| **gradient**（默认） | 橙红渐变 | 工具推荐、教程、常规更新 | 醒目、有行动感，货架里最跳 |
| **dark** | 深色 + 橙红光晕 | 深度评测、观点文、AI 资讯 | 高级、克制、科技感 |
| **light** | 暖白 | 轻量话题、生活类、快讯 | 清爽、易读、亲和 |

> 建议用法：**常规栏目固定一种风格**（如教程全用 gradient、资讯全用 dark），
> 读者刷信息流时能靠颜色认出你的栏目，形成栏目视觉资产。

---

## 四、尺寸说明

| 尺寸 | 像素（2x 实际输出） | 用途 |
|---|---|---|
| **wide** | 900×383 → **1800×766** | **公众号头条封面（2.35:1 标准比例）** |
| square | 800×800 → 1600×1600 | 分享卡片、次条方图、视频号封面 |
| og | 1200×630 → 2400×1260 | 外部平台分享（知乎/掘金/即刻等） |

> 公众号后台封面上传建议直接用 wide 的 2x 输出（1800×766），
> 微信会自行压缩展示，高清源保证缩放后不糊。

## 五、排版自动规则（写标题时参考）

1. **标题建议 6~16 字**，超出会自动缩小字号；两行以内效果最佳
2. **手动换行**用 `\n`，在语义断点处换（如 `AI 帮你写周报\n10 分钟搞定 3 小时的活`）
3. 字号自适应按**最长行**计算——两行字数接近时视觉最平衡，一行极长一行极短会偏小
4. 副标题建议 ≤ 20 字，一行放得下最好
5. 左上 `--tag` 适合放**栏目名 / 期数**，养成固定格式（如「AI 工具 · 第 12 期」）读者会认

## 六、想要新风格 / 改品牌色

打开 `make-cover.py`：

- **加新风格**：复制 `STYLES` 里任意一段改色值即可，无需动排版
- **换品牌主色**：改文件顶部 `BRAND["gradient"]` 一处，全部风格联动
- **换品牌名 / Slogan**：改 `BRAND["name"]`

装饰元素（右上大气泡、右下圆标 logo + 品牌名）所有风格自动携带，与「码上聊聊」图标同源。
