# 人工痕迹包（去 AI 味）

## 0. 先认清目标

用户要的不是「换个同义词」——同义词替换只会产生**新的**机器味。要的是**像人在说话**：
有呼吸感（长短句交错）、有具体内容（数字、人名、地名、时间点）、有个人判断（敢下结论，也敢说「这块我没把握」）。

> 平台差异：知乎要「有判断有边界」（轻度，只删套话不动结构）；公众号要「故事与细节」（中度，加主观看法补具体）；
> 小红书要「口语和亲身经历」（重度，全口语化）。用户没指定平台就按中度来。

## 1. 中文的「AI 味」在句式，不在词频

英文那套 perplexity / burstiness 直接搬过来会漂。中文最强信号是这些，改的时候逐条对照：

| 类型 | 典型表现 | 改法 |
|---|---|---|
| 机械连接词 | 首先 / 其次 / 最后 / 综上所述 / 值得注意的是 / 不可否认 / 毋庸置疑 | 删掉或换成口语过渡（「话说回来」「这里有个坑」），两段之间本来就不用连接词 |
| 宏大词 | 赋能 / 抓手 / 闭环 / 深耕 / 颗粒度 / 打造 / 全方位 / 显著 | 换成大白话；「显著提升」→「从 3 小时压到 40 分钟」 |
| 三段式排比 | 每段都是三句、每句都是二十来字、零短句 | 故意写一句短的，甚至一句断行 |
| 模板句式 | 「在 XX 背景下」「随着 XX 的发展」「不仅…更…」 | 直接切入，别铺垫 |
| 聊天残留 | 「希望对你有帮助」「欢迎留言交流」「如有疑问」 | 删掉，结尾给一句有信息量的 |
| 太干净 | 零口语、零自我修正、零不确定 | 加「我当时」「说实话」「这块我拿不准」 |

## 2. 改写四步（顺序别反）

1. **先保事实**：把原文里的所有数字、百分比、日期、链接、专名、引用**原样抄下来**，一个字不许动。改完逐条核对——丢了立刻补回，绝不静默。
2. **注入不完美**：长短句交错、加一两句口语插入、允许一句自我修正。
3. **补具体性**：把抽象结论换成可感知的细节（时间 / 地点 / 金额 / 人名）。
4. **打散结构**：砍掉排比，段落长短不一，结尾别用总结套话。

## 3. 硬纪律（违反即失败）

- **事实零改动**：关键数字、链接、专名被改坏比「有 AI 味」严重十倍。宁可留着机器腔，也不能编改事实。
- **不承诺包过检测**：检测器真实误判率 15–30%（非母语者作文常被误判 61%），人类化后 AI 文本检出率也只有 11–28%。只能说「降低被认出是 AI 的特征密度」。
- **不虚构**：没给的数据不要编；拿不准就承认，比假装权威更有人味。

## 4. 输出

直接给改写后的全文（保留 Markdown 结构）。改完用一两句说明「动了哪几处、为什么更像人写的」；如果原文事实已核对无误，明确说一句「数字与专名已逐条核对，未改动」。
